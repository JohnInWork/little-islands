# DNG Codex

Пиксельный рогалик для телефона, в который играют одним пальцем. Герой бьётся
сам — игрок решает, куда идти, что поднять, что надеть, чему учиться и
когда отступить.

[Как выпускать](docs/RELEASE.md) · [Начать разработку](docs/START-HERE.md)
· [Следующие задачи](docs/NEXT-TASKS.md)

Название репозитория `little-islands` сохранено ради старых ссылок; игра,
PWA и сохранения называются **DNG Codex**. Версия из `package.json` видна в
главном меню.

![Забег DNG Codex на телефоне](screenshots/dungeon-mobile.png)

## Что в игре

- **18 этажей в трёх главах** со стражем в конце каждой и ещё шесть за концом
  дороги; пять дорог — пещеры, земли за воротами, старые подвалы, склепы и ад.
- **Город на нулевом этаже**: торговцы, таверна с наёмниками, храм, дом,
  который покупается и обставляется; портал ведёт туда из подземелья.
- **27 навыков по три ранга** и одна копилка очков на навыки и три
  характеристики. Шесть школ магии: каждый ранг открывает заклинания,
  книги поднимают навык до конца забега, три слота под рукой.
- **140 предметов снаряжения**, все видны на герое; 20 уникальных сил
  артефактов — каждая не больше одного раза за забег.
- **288 существ**, 73 уникальных: стражи глав, драконы, именные скитальцы,
  переговоры с некоторыми из них.
- Голод, сон, охота и готовка; запертые сундуки, мимики, ловушки и набор
  сапёра; копилка между забегами на стартовые припасы.
- Пиксельный шрифт Fusion Pixel на всех языках, RU/EN, справка «?» в меню,
  яркость в настройках, работа без сети после первой загрузки.

## Управление

- Телефон: касание по разведанному полу или крестовина внизу; рюкзак и
  «что рядом» — слева внизу.
- Компьютер: WASD или стрелки, E или пробел — действие рядом, 1–3 —
  заклинания, M — карта, Esc — пауза.
- Бой автоматический; вещь с пола берут кнопкой «что рядом». Меню и окна
  ставят мир на паузу.

## Запуск

Нужен Node.js `^22.13.0` или `>=24`.

```bash
npm ci
npm run check   # 1000+ тестов и сборка
npm run dev
```

Главная страница перенаправляет на `/tools/dcss.html`. QA-параметры адреса:
`?seed=N` — фиксированный забег, `?shot=1` — кадр без интерфейса, `?qa=1` —
служебный режим для бота (`npm run qa:bot`).

## Выпуск

`npm run package:itch` собирает `release/dng-codex-itch.zip` — около 350
файлов: спрайты режутся из атласа. Тексты страницы, настройки itch.io и
чеклист — в [docs/RELEASE.md](docs/RELEASE.md).

Стек: Vite, JavaScript ESM, Canvas и Three.js для стен, света и теней.

## Графика, звук и шрифт

Тайлы — [Dungeon Crawl Stone Soup](https://github.com/crawl/tiles) (CC0);
полы, таверна, город и фонари — художники Liberated Pixel Cup (CC-BY и
CC-BY-SA); сундуки — Cmski; значки — game-icons.net (CC BY 3.0) и 7Soul1
(CC0); шрифт — Fusion Pixel Font (OFL); звук и музыка — CC0-записи. Полный
список с лицензиями — на экране «Авторы» в игре и в
[THIRD_PARTY_ASSETS.md](THIRD_PARTY_ASSETS.md).
