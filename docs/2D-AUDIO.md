# DNG Codex — звук

Игра не содержит аудиофайлов: каждый звук синтезируется WebAudio по небольшому
рецепту из данных, поэтому лицензионных вопросов нет, а сборка не растёт.

## Контракт

Файл: `tools/dcss-rpg-audio.js` (чистый), адаптер и планирование голосов —
`tools/dcss.js`.

- `SOUND_RECIPES` — карта `id → голоса`. Голос: `type`
  (`sine|square|triangle|sawtooth|noise`), `from`/`to` (Гц, для шума — полоса
  фильтра), `gain` (не выше 0,06), `duration` (0,02…1,2 с), `delay`, `attack`.
  `soundRecipeProblems()` проверяет границы в тестах.
- `AMBIENT_RECIPES` — фоновый слой на палитру главы (`slate`, `ochre`, `ice`,
  `ember`): два дрона, фильтрованный шум и медленное дыхание. Неизвестная палитра
  падает в `slate`.
- Настройки: один документ `dng-codex:audio:v1` в localStorage
  (`{ volume: 0…1 шагом 0,1, muted }`), не входят в save забега. Мусор в
  хранилище заменяется значениями по умолчанию (70 %, звук включён).
- `audioMenuModel()` даёт RU/EN подписи для ряда в главном меню: mute,
  «Тише», текущий процент, «Громче».

## Адаптер

- Все голоса, включая старые (левел‑ап, акцент мечей, треск молнии), идут через
  один master gain; меню меняет только его. `playSound(id)` молчит, пока
  AudioContext не разблокирован жестом или пока громкость равна нулю.
- Фон стартует после разблокировки и переключается вместе с палитрой этажа в
  `replaceFloor()`; пауза приглушает его, смерть и победа останавливают.
- Точки событий: удар по врагу (клинок / тяжёлый / снаряд), урон и блок героя,
  убийство, подбор предмета и золота, дверь, спуск, заклинания (огонь, лёд,
  лечение, переключаемые), еда, зелья, книги, ловушка, смерть, победа, открытие
  рюкзака, карты и панели действий, вход в паузу.

## Как добавить звук

1. Одна запись в `SOUND_RECIPES` с тихими голосами; прогнать
   `tests/dcss-rpg-audio.test.js`.
2. Один вызов `playSound('id')` в точке события адаптера, после того как чистая
   команда подтвердила результат. Звук не решает исход и не выдаёт награды.
3. Для нового фона — запись в `AMBIENT_RECIPES` по id палитры из
   `ATMOSPHERE_THEMES`.
4. Runtime‑тесты, которые запускают функции адаптера в `vm`, получают заглушки
   `playSound`, `startAmbient`, `stopAmbient`, `setAmbientLevel`.

Не добавлять внешние аудиофайлы без лицензии рядом с ними и записи в
`THIRD_PARTY_ASSETS.md`; не создавать второй AudioContext.
