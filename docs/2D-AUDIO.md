# DNG Codex — звук

Каждый звук имеет синтез-рецепт для WebAudio и, для большинства событий,
CC0-сэмпл, который подменяет синтез, когда файл загрузился. Без каталога
`public/assets/audio/` игра звучит синтезом, лицензионных вопросов нет.

## Контракт

Файл: `tools/dcss-rpg-audio.js` (чистый), адаптер, загрузка файлов и
планирование голосов — `tools/dcss.js`.

- `SOUND_RECIPES` — карта `id → голоса`. Голос: `type`
  (`sine|square|triangle|sawtooth|noise`), `from`/`to` (Гц, для шума — полоса
  фильтра), `gain` (не выше 0,06), `duration` (0,02…1,2 с), `delay`, `attack`.
  `soundRecipeProblems()` проверяет границы в тестах.
- `AMBIENT_RECIPES` — фоновый слой на палитру главы (`slate`, `ochre`, `ice`,
  `ember`): два дрона, фильтрованный шум и медленное дыхание. Неизвестная палитра
  падает в `slate`.
- `SOUND_SAMPLES` — карта `id → { file, gain }` поверх рецептов: 21 эффект из
  CC0-паков (8-битная коллекция Juhani Junkala, RPG Sound Pack artisticdude).
  `AMBIENT_SAMPLES` — петля подземелья JaggedStone на каждую палитру со своим
  `gain`. `AUDIO_SAMPLE_ROOT` (`../assets/audio/` от `tools/dcss.html`) и
  `AUDIO_SAMPLE_FILES` (уникальные файлы для предзагрузки).
  `audioSampleProblems()` требует, чтобы у каждого сэмпла был рецепт-запасной
  вариант, путь вида `sfx|ambience/<kebab>.mp3` и `gain` в (0; 0,5].
- Файлы: моно MP3 44,1 кГц, пик −3 dBFS, ~0,9 МБ на всё; список и авторы —
  `public/assets/audio/LICENSE.md`, запись в `THIRD_PARTY_ASSETS.md`.
- Настройки: один документ `dng-codex:audio:v1` в localStorage
  (`{ volume: 0…1 шагом 0,1, muted }`), не входят в save забега. Мусор в
  хранилище заменяется значениями по умолчанию (70 %, звук включён).
- `audioMenuModel()` даёт RU/EN подписи для ряда в главном меню: mute,
  «Тише», текущий процент, «Громче».

## Адаптер

- Все голоса и сэмплы, включая старые (левел‑ап, акцент мечей, треск молнии),
  идут через один master gain; меню меняет только его. `playSound(id)` молчит,
  пока AudioContext не разблокирован жестом или пока громкость равна нулю.
- После первого жеста `preloadAudioSamples()` тянет все файлы `fetch` +
  `decodeAudioData` и кладёт буферы в кэш по имени файла; неудача запоминается
  как `null` и не повторяется, событие звучит синтезом. До загрузки
  `playSound()` тоже играет синтез.
- Фон стартует после разблокировки и переключается вместе с палитрой этажа в
  `replaceFloor()`; пока петля не декодирована, играет синтез-подстилка, а после
  загрузки `startAmbient()` сам пересобирает фон на сэмпл (`sampled: true`).
  Пауза приглушает фон, смерть и победа останавливают.
- Точки событий: удар по врагу (клинок / тяжёлый / снаряд), урон и блок героя,
  убийство, подбор предмета и золота, дверь, спуск, заклинания (огонь, лёд,
  лечение, переключаемые), еда (только синтез), зелья, книги, ловушка, смерть,
  победа, открытие рюкзака, карты и панели действий, вход в паузу.

## Как добавить звук

1. Одна запись в `SOUND_RECIPES` с тихими голосами; прогнать
   `tests/dcss-rpg-audio.test.js`.
2. Один вызов `playSound('id')` в точке события адаптера, после того как чистая
   команда подтвердила результат. Звук не решает исход и не выдаёт награды.
3. Для нового фона — запись в `AMBIENT_RECIPES` по id палитры из
   `ATMOSPHERE_THEMES`.
4. Сэмпл — только CC0 или с лицензией на коммерческое использование: файл в
   `public/assets/audio/sfx/` (моно MP3, пик −3 dBFS, короткий), строка в
   `public/assets/audio/LICENSE.md`, запись в `SOUND_SAMPLES` с `gain`
   0,07…0,3. Тест проверяет наличие файла, размер и строку в уведомлении.
5. Runtime‑тесты, которые запускают функции адаптера в `vm`, получают заглушки
   `playSound`, `startAmbient`, `stopAmbient`, `setAmbientLevel`.

Не добавлять аудиофайлы без лицензии рядом с ними и записи в
`THIRD_PARTY_ASSETS.md`; не создавать второй AudioContext и не использовать
`new Audio()` в обход master gain.
