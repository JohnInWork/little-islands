# DNG Codex — лагерь

Лагерь — маленькая локация, которую герой строит сам. Не комната подземелья,
а три предмета вокруг героя: костёр, спальник, сундук. Чем выше навык, тем
больше предметов и тем иначе лагерь выглядит.

| Ранг навыка «Лагерь» | Что появляется | Отдых | Сундук |
| --- | --- | --- | --- |
| 1 | костёр | — | — |
| 2 | костёр, спальник | 25 % здоровья | — |
| 3 | костёр, спальник, сундук | 40 % здоровья | 8 ячеек, переезжает между этажами |

Костёр лагеря — тот же, что в подземелье: на нём готовят сырое мясо тем же
действием «Приготовить». Отличается только тем, что его принёс герой.

## Как поставить

Нужен **походный набор** (`camp-kit`) — инструмент из рюкзака, «Использовать».
Набор тратится за лагерь: поставил — набора нет. Набор падает с первого этажа
и продаётся у торговцев.

Отказ называет причину, потому что набор слишком редкий, чтобы тратить его
на догадки:

| Причина | Текст |
| --- | --- |
| `no-skill` | Нужен навык «Лагерь» |
| `no-kit` | Нужен походный набор |
| `already-pitched` | Лагерь уже разбит |
| `unsafe-ground` | Здесь не встать |
| `enemies-near` | Рядом враги |
| `no-room` | Мало места |

`CAMP_SAFE_DISTANCE = 6`: лагерь не ставится в шести клетках от живого
монстра, **который видит это место**. Стена между ними снимает запрет —
рантайм фильтрует угрозы через `hasLineOfSight`. Без этого фильтра на
нетронутом первом этаже подходящих клеток оказывалось две на всю карту.

Один лагерь на этаж. Спуск оставляет лагерь позади, а сундук едет с героем.

## Отдых

Спальник даёт один сон на лагерь: здоровье за время. Цена —
`CAMP_REST_HUNGER_COST = 420` из 3600 секунд шкалы голода. Слишком голодный
герой получает `too-hungry` и не засыпает голодным.

Процент отдыха живёт **в самом лагере**, а не в навыке: `camp.restPercent`.
Поэтому призванный заклинанием лагерь спит хорошо без навыка, а построенный
не меняется от того, что герой изучит потом.

## Сундук

Личное хранилище между этажами. Переиспользует весь контракт сундуков
(`dcss-rpg-chest-containers.js`) через один зарезервированный
`findId = 'camp-stash'`: тот же двухпанельный экран, те же переносы, та же
проверка сохранения. Живёт в `run.camp.stash`, а не в `run.floor.chests`,
поэтому `advanceRunFloor` копирует его на новый этаж. В шапке экрана он
называет себя «Сундук лагеря», чтобы не путался с находками подземелья.

## Заклинание «Зов лагеря»

`camp-call`, школа Арканистики, интеллект 8, перезарядка 150 секунд. Ставит
лагерь без набора. Книга `book-of-camp-call` падает с третьего этажа.

`summonedCampProfile(capabilities)` берёт максимум из заклинания и навыка:
никогда не меньше костра со спальником и 30 % отдыха, но сундук остаётся
наградой навыка. Правила безопасности заклинание не отменяет — рядом с тем,
кто видит место, лагеря не будет и по магии.

## Контракт

Чистый модуль: `tools/dcss-rpg-camp.js`.

- `campProfile(capabilities)` → `{ rank, features, restPercent, stashSlots }`;
  `summonedCampProfile(capabilities)` — то же для заклинания.
- `campLayout({ cell, features, grid, occupied })` расставляет предметы по
  восьми соседям в постоянном порядке, поэтому одно и то же место всегда даёт
  один и тот же лагерь. Не хватило клеток — пустой список, лагеря нет.
- `canPitchCamp({ profile, kits, camp, grid, cell, occupied, threats, needsKit })`
  → `{ ok, reason, places }`. `needsKit: false` — это и есть заклинание.
- `createCampState({ cell, places, rank, restPercent })`, `validateCampState`.
- `resolveCampRest({ camp, hp, maxHp, hunger })` → `{ ok, reason, healed, hp, hunger, camp }`.
- `createCampStash(source)`, `validateCampRunState(camp)`.
- `campRefusalText(reason, language)` — короткие подписи отказа, ru и en.
- `CAMP_ASSET_PATHS` — спрайты лагеря; `requiredAssetPaths()` подхватывает их,
  поэтому сборка для itch.io везёт костёр, спальник и сундук.

Рантайм: `placeCamp(profile, { needsKit })` в `tools/dcss.js` — одна дорога
для набора и для заклинания, разница только в цене.
