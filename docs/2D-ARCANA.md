# DNG Codex — неизвестная аркана

Неизвестные зелья, свитки, жезлы и книги используют один контракт опознания,
но сохраняют разные способы применения. Истинный `contentId` не меняется;
seed забега назначает каждому типу безопасную внешность, а журнал знаний хранит
только уже раскрытые ID.

## Что работает

- **Зелья** расходуются при питье и применяют объявленный `potionEffect`.
- **Свиток скачка** расходуется и переносит героя через общий `useEffect`.
- **Костяной жезл** сохраняет зарядный стек и применяет существующий эффект.
- **Учебник мастерства** при чтении добавляет один эффективный ранг случайному
  готовому навыку на текущий забег.
- **Книга забвения** отнимает один эффективный ранг у случайного активного навыка.
- **Пустой кодекс** расходуется, раскрывается и намеренно ничего не делает.

До опознания имя, иконка, редкость, цена, tier и эффект настоящего предмета не
попадают в UI. Одинаковый истинный тип получает одинаковую внешность в одном
забеге; новый seed может назначить другую. Оценка I/II/III работает со всеми
четырьмя семействами соответствующего tier.

## Книги и очки навыков

`hero.skills` остаётся единственным источником заработанных очков и изученных
рангов. Книги не меняют его и не нарушают инвариант
`points + сумма ranks === level - 1`.

Результат чтения хранится отдельно в `hero.skillStudy`:

```js
{
  version: 1,
  rankAdjustments: { swords: 1, appraisal: -1 },
}
```

Правила и бой всегда используют эффективный ранг:
`trained rank + book adjustment`, ограниченный диапазоном `0…maxRank`.
Положительная и отрицательная книга одного навыка взаимно сокращаются. Книга
может открыть ранг раньше обычного требования уровня; собственное очко игрок
всё равно тратит только через обычную команду изучения. Меню показывает
изученный ранг и отдельную понятную поправку книги.

## Границы модулей

- `tools/dcss-rpg-identification.js` — семейства, seed-внешности, безопасный вид,
  журнал знаний и Оценка.
- `tools/dcss-rpg-books.js` — строгая форма `skillStudy` и чистая команда
  `read-book` с событиями результата.
- `tools/dcss-rpg-skills.js` — вычисление эффективного ранга и общие эффекты.
- `tools/dcss-rpg-content.js` — истинные предметы и декларативные эффекты.
- `tools/dcss.js` — только применение подтверждённого результата, расход стека,
  звук и уведомление.

Новый вид арканы сначала получает чистое правило эффекта и тесты. Затем в каталог
добавляются стабильный ID, `identification: { group, tier }` и существующая
локальная внешность. Нельзя ветвить механику по отображаемому имени или цвету.

Save v26 хранит `hero.skillStudy`; v25 и более старые сохранения получают пустые
поправки без изменения изученных рангов, очков, экипировки и текущего этажа.

## Проверка

`tests/dcss-rpg-books.test.js` проверяет три исхода книг, детерминированный выбор
навыка, сохранение бюджета очков, отмену противоположных эффектов, отсутствие
утечек во всех четырёх семействах, save/migration и runtime-связывание.
Остальной контракт закрывают `dcss-rpg-identification.test.js`,
`dcss-rpg-skill-menu.test.js`, `dcss-rpg-merchant.test.js` и общий `npm run check`.
