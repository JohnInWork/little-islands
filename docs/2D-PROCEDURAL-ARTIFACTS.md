# DNG Codex — процедурные артефакты

## Простое правило для игрока

Вещь имеет один из трёх понятных уровней:

- обычная — только базовые характеристики;
- магическая — одно небольшое свойство или иммунитет;
- артефакт — одна редкая бинарная сила, которая меняет способ игры.

У полёта и невидимости нет слабой и сильной версии. Артефакт либо даёт силу
полностью, либо не даёт её. Редкий проклятый артефакт сохраняет сильную способность,
но получает один заранее понятный недостаток. Скрытых проклятий у нового лута нет.

## Первая волна сил

| ID | Совместимость | Реальный эффект |
| --- | --- | --- |
| `flight` | любая экипировка | ловушки не срабатывают; можно проходить над опасным полом |
| `invisibility` | любая экипировка | враги теряют героя; атака раскрывает его на 3 секунды |
| `vampirism` | оружие | 20% фактически нанесённого оружием урона лечит героя |
| `three-wards` | броня, щит, украшение, фокус | иммунитет к огню, холоду и яду |

Проклятия первой волны: `frailty` (−18 здоровья), `burden` (−14% движения),
`exposure` (−3 защиты). Они видимы в названии и карточке до надевания.

## Генерация и экономика

`tools/dcss-rpg-artifacts.js` владеет каталогами, совместимостью, отдельным
seeded RNG и материализацией. Этаж сначала решает, будет ли на нём артефакт, и
лишь затем выбирает одну основу среди уже отобранного лута. Поэтому увеличение
`lootAbundance` не умножает шанс сильной вещи. На этаже бывает максимум один
артефакт, а один из этажей II–III гарантирован для каждого полного забега.

`DEFAULT_ARTIFACT_RATE` — единый коэффициент частоты случайных артефактов:
`0` отключает их, `1` — целевой режим, допустимый диапазон `0…3`. Гарантия также
отключается при `0`, что удобно для изолированных тестов.

Экземпляр хранит только:

```js
{
  artifactPowerId: 'flight',
  artifactCurseId: 'burden' // либо null
}
```

Название, золотая редкость, итоговые stats/magic и RU/EN-описание вычисляются.
Визуальная основа и paper-doll остаются у базового предмета. Артефакт не получает
дополнительный малый affix, чтобы правило «одна большая сила» не размывалось.

## Как добавить силу

1. Реализовать чистое игровое правило без проверки ID предмета.
2. Подключить его к runtime и добавить визуальную обратную связь.
3. Добавить один объект в `PROCEDURAL_ARTIFACT_POWERS`: ID, теги, RU/EN-суффикс,
   `magic` и вес.
4. Добавить словарный факт в генератор описаний.
5. Проверить совместимость, seed, save/reload, надевание/снятие и RU/EN.

Save v22 хранит стабильные ID. Миграция v20 сохраняет существующие affix,
удаляет прежние поля скрытой святости и не создаёт артефакт задним числом.
Артефакты из v21 сохраняют силу и явное проклятие. Generator v6, content v11.
