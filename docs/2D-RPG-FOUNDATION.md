# 2D RPG — рабочая основа

## Направление

Главное направление проекта — мобильная 2D roguelike/RPG на CC0-графике Dungeon
Crawl. Старая 3D-игра остаётся в репозитории только как архив совместимости и не
получает новые функции. Пока рабочая точка входа — `/tools/dcss.html`; переключение
production-entry выполняется отдельно, когда вертикальный срез будет готов к публикации.

Короткая формула игры: **укажи путь → исследуй → герой сам сражается и собирает →
реши, что оставить → спустись глубже → собери новый билд**.

## Уже работающий вертикальный срез

- детерминированные этажи из комнат, коридоров и дополнительных циклов;
- проверяемый путь от безопасного старта до лестницы;
- туман войны и постепенное открытие карты;
- тап/клик по видимой клетке и WASD, остальное герой делает сам;
- преследование и автобой с ростом силы противников по глубине;
- опыт, уровни, лечение, сила и смерть с новым забегом;
- автоматический подбор, 12 мест, восемь слотов, расходники и массовый разбор;
- четыре автоматических события: фонтан, алтарь, ловушка и саркофаг;
- лестница создаёт новый этаж, а каждые два этажа меняется визуальная тема;
- versioned localStorage-save с резервной копией и восстановлением этажа по seed.

## Границы модулей

- `tools/dcss-rpg-content.js` — только каталоги монстров, предметов и событий.
  Новую сущность добавлять сюда, не в игровой цикл.
- `tools/dcss-rpg-core.js` — чистые RNG, генерация, поиск пути, туман, save-schema
  и валидация. Файл не знает про canvas и DOM и покрыт seed-sweep тестами.
- `tools/dcss.js` — адаптер браузера: canvas, анимация, ввод, автоматический бой,
  HUD и безопасные границы сохранения.
- `tools/dcss.css` / `tools/dcss.html` — крупный пиксельный UI, safe-area и
  portrait/landscape раскладка.

## Контентная база

В `public/assets/dcss-preview/` лежит полная локальная библиотека `mon`, `item`,
`player` и `dngn` из CC0-экспорта Dungeon Crawl: 3383 PNG. Неиспользуемые файлы не
загружаются браузером. Первый активный каталог намеренно ограничен 24 монстрами,
36 предметами, четырьмя событиями и четырьмя темами этажей: сначала балансируем
петлю, затем расширяем таблицы.

## Неподвижные контракты

1. Один seed и глубина всегда создают тот же этаж, спавны и таблицы.
2. Генератор возвращает только plain data; canvas ничего не решает о правилах.
3. Каждый выход достижим, попытки размещения ограничены.
4. Все ID стабильны; сохранение хранит ID, seed и решения, а не DOM/спрайты.
5. Старое или повреждённое сохранение не ломает запуск; будущая версия не
   интерпретируется догадками.
6. Управление остаётся простым: путь задаёт игрок, бой и подбор автоматические.
7. Экран по умолчанию почти без слов; сложные решения живут в паузе/рюкзаке.

## Как добавить контент

Монстр: добавить запись с уникальным `id`, существующим `path`, `tier`, `hp`,
`damage`, `speed` и `xp`. Генератор сам допустит его на подходящей глубине.

Предмет: добавить уникальный `id`, `icon`, `slot`, `variant`, `rarity`, `weight`
и `minDepth`. Для видимого оружия/брони сначала добавить соответствующий слой в
массив `gear` в `tools/dcss.js`; предмет без визуального варианта не выпускать.

Событие: добавить уникальный `id`, `path`, `effect`, `value` и `weight`. Новые
типы эффекта реализуются один раз в `resolveWorldInteractions`, после чего
множество событий может использовать тот же эффект.

## Следующие слои глубины

1. Неизвестные зелья/свитки, проклятия и идентификация как в NetHack.
2. Дальние атаки, сопротивления, яд, огонь, холод и синергии экипировки.
3. События с двумя иконками выбора вместо текста.
4. Мини-боссы, уникальные комнаты и гарантированные редкие награды.
5. Хаб между забегами, коллекция найденного и простая мета-прогрессия.

Единый шлюз перед передачей изменений: `npm run check`.
