# DNG Codex — вода

Единственная жидкость подземелья — мель (клетка `~`). Она проходима для всех,
но каждый, кто в ней стоит, мокрый, медленный и бьёт слабее, а связанная лужа
проводит молнию на всех, кто в ней стоит, включая героя. Затопленный зал —
редкая комната (около трети этажей) на любой главе.

## Контракт

Файл: `tools/dcss-rpg-terrain.js` (чистый); генерация — `dcss-rpg-core.js`;
адаптер читает только булевы.

- `WATER_CELL = '~'`; `isWalkableCell()` в core считает воду проходимой и
  прозрачной для LOS, BFS и раскрытия, поэтому вода никогда не режет маршрут.
- Правила: `terrainSpeedMultiplier({ inWater, terrain })` — по умолчанию
  ×0,75 в воде, ×1 на суше; `terrainMeleeMultiplier()` — ×0,85 в воде для
  всех, кроме существ с профилем воды ≥ 1; `terrainAllowsCell()` — существо с
  `terrain.land === 0` не покидает воду. Профиль монстра — поле `terrain:
  { water, land }` в каталоге, у героя профиля нет.
- Статус: в воде каждый актёр держит `wet` (обновляется, пока таймер меньше
  `WATER_WET_REFRESH_BELOW`, и ещё `WATER_WET_DURATION` секунд после выхода).
  Полёт снимает штрафы и мокроту с героя. Горение гаснет по правилам
  `dcss-rpg-effects.js`; холод на мокром длится в полтора раза дольше;
  Криомантия II замораживает мокрого — всё это в воде срабатывает само.
- Молния: `selectWaterConductionTargets({ grid, origin, actors, tileSize,
  exclude })` — все актёры в связанной луже цели (`waterPoolCells`, BFS по
  четырём соседям), кроме уже задетых цепью; урон
  `WATER_CONDUCTION_PERCENT` = 60 % от снаряда, герой получает прямой урон с
  источником `spell:storm` («Собственная молния» на экране итогов).
- Огонь: Огненная стрела по цели в воде — ×`WATER_FIRE_MULTIPLIER` (0,5) и
  пар. Книги в воде не читаются (мокрые страницы), зелья пьются.
- Генерация: свой поток `mixSeed(floorSeed, 'WATR')`; `chooseFloodedRoom`
  берёт одну комнату с шансом `WATER_ROOM_CHANCE` (0,3), исключая стартовую,
  выходную, комнату святилища, хранителя и сюрприза; `floodRoom` оставляет
  сухой фартук вокруг каждого прохода и события/фауны и 1–2 сухих острова.
  Затопление идёт до находок и планов комнат, поэтому лут, находки и фауна
  сухого этажа не меняются; торговец обходит комнаты с водой. Меньше четырёх
  клеток воды — комната остаётся сухой. Уровень возвращает `floodedRoomIndex`.
- Существа воды (`spawn: 'water'`, не входят в случайный пул и не становятся
  стражами сундуков): электрический угорь (`terrain { water: 1.25, land: 0 }`,
  `shock: { radius: 2 }` — укус бьёт током всех мокрых в двух клетках, своих
  тоже) на каждом затопленном этаже, мерфолк-копейщик (`water 1.35 / land
  0.7`, спрайт `waterPath` в воде) с III этажа.
- Save v36, generator 8: сетка не хранится, этаж пересобирается из seed;
  старые v31–v35 мигрируют пересборкой, позиции остаются проходимыми.

## Адаптер

- `updateHeroTerrain()` в начале `updateWorld()`: мокрота, всплеск
  (`splash`, две вариации) и брызги при входе. Монстры получают мокроту в
  своём цикле. Скорость и урон домножаются через модуль.
- Угорь маршрутизируется только по воде (`findPath(..., { terrain })`) и не
  может шагнуть на сушу; мерфолк ходит везде со своим профилем.
- Визуал: тайлы `shallow_water*` с анимацией только на разведанных клетках,
  спрайт в воде опущен на 6 px и с тусклой тенью, поверх ног — рябь
  (`drawWaterlines`). Карта этажа красит воду в `FLOOR_MAP_COLORS.water`.
