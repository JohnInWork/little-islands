# Статусные эффекты 2D RPG

Рабочий контракт этапа 2. Реализованы пять общих состояний актёра: `burning`,
`wet`, `chilled`, `frozen`, `poison`. Источник правил — `tools/dcss-rpg-effects.js`;
renderer и каталог не должны отдельно пересчитывать длительность, урон или реакции.

## Правила

| ID        | Игровое действие              | Визуальная обратная связь                              |
| --------- | ----------------------------- | ------------------------------------------------------ |
| `burning` | 2 прямого урона раз в секунду | языки пламени, искры, дым, тёплый локальный WebGL-свет |
| `wet`     | −4% скорости                  | капли с тела, блики и расходящееся кольцо воды у ног   |
| `chilled` | −26% скорости                 | иней на силуэте, холодные искры и дыхание              |
| `frozen`  | останавливает движение и атаку| крупные пиксельные кристаллы вокруг силуэта             |
| `poison`  | 1 прямого урона раз в секунду | поднимающиеся зелёные пузырьки и слабая аура у ног     |

Мокрота тушит горение с реакцией пара. Попытка поджечь мокрую цель сначала
высушивает её и не накладывает горение. Холод на мокрой цели длится в 1.5 раза
дольше и дополнительно замедляет её. Все длительности ограничены 60 секундами.

Эффекты тикают только в активной игре: меню, рюкзак и экран характеристик ставят
их на паузу. Урон эффектов обходит физическую броню. Он может убить героя и
использует ту же терминальную смерть, что обычный бой.

## Источники первой вертикали

- Жезл прилива вручную накладывает `wet` на выбранного видимого врага; если цель
  горит, общий обработчик эффектов тушит пламя и создаёт реакцию пара;
- фонтан делает героя мокрым;
- огненный алтарь даёт силу, но поджигает;
- заражённые крысы и пауки отравляют;
- призраки и хранитель глубин охлаждают;
- огненные демоны, адские гончие и огненные боссы поджигают.

`MONSTER_CATALOG[].inflicts` и `EVENT_CATALOG[].status` содержат только ID и
длительность. Вся обработка проходит через `applyActorEffect`, чтобы новые
источники не могли обойти реакции.

## Представление и сохранение

Постоянное состояние находится в `hero.effects` и состояниях живых монстров.
Save v34 валидирует полный объект из пяти конечных значений; миграция v28
добавляет нулевую заморозку, не теряя уже активные эффекты и текущий этаж.

HUD показывает большие пиксельные иконки и целое число оставшихся секунд. RU/EN
названия берутся из определения эффекта. Canvas-FX квантуются к 2–4 CSS-пикселям;
при `prefers-reduced-motion` сохраняются статические признаки состояния без
активного движения. Пламя дополнительно регистрирует источник в существующей
системе объёмного WebGL-света, поэтому освещает пол и стены, а не выглядит
наклейкой поверх героя.

## Как добавить новый эффект

1. Добавить стабильный ID в `ACTOR_EFFECT_IDS` и полное определение в
   `ACTOR_EFFECTS` с двумя языками, локальной иконкой и числовыми правилами.
2. Определить взаимодействия в `applyActorEffect` и механику в
   `actorEffectModifiers`/`tickActorEffects`.
3. Добавить один выразительный, но компактный визуальный мотив в `dcss.js`.
4. Подключить источники только через `inflicts`/`status` или будущий предметный
   effect intent; не изменять `hero.effects` напрямую.
5. Если меняется форма сохранения, поднять save version и написать миграцию.
6. Дополнить `tests/dcss-rpg-effects.test.js`, затем выполнить `npm run check` и
   проверить portrait/landscape, оба языка и ошибки консоли.
