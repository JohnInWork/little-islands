# DNG Codex — записи между забегами

Герой начинает каждый забег с нуля — это правило не меняется. Между забегами
живёт **память о том, что было**, а не преимущество: таблица лучших забегов,
итоги за всё время, вехи и сид дня.

## Что хранится

| Часть | Что это |
| --- | --- |
| Лучшие забеги | пять записей: этаж (или «Победа»), убийства, золото, время, сид |
| Всего | забегов, побед, золота, глубже всего, побед в забеге, время в подземелье |
| Вехи | восемь фактов о пройденном: первая кровь, третий этаж, дом, розыск, пятый этаж, пятьсот золота, девятый этаж, победа |
| Сид дня | один сид на сутки (UTC), одинаковый у всех |

Порядок в таблице: победа выше любой смерти, затем глубина, затем убийства,
затем золото, затем время. Экран итогов ставит «Новый рекорд ★», когда забег
встал выше всех прежних.

**Вехи ничего не выдают.** Ни предмета, ни заклинания, ни очка — только
отметка. Это сознательно: старт с нуля остаётся стартом с нуля, а
мета-прогрессия не превращается в постепенное усиление.

## Где это лежит

Свой ключ `dng-codex:meta:v1`, **рядом с сохранением, а не внутри него**. Из-за
этого история переживает смерть, смену генератора и очищенный сейв. Проверка
сохранения о записях ничего не знает, и наоборот.

Испорченное хранилище — это история, которой не было: `parseMeta` возвращает
пустую запись вместо ошибки.

## Устройство

Чистый модуль `tools/dcss-rpg-meta.js`:

- `createMetaState(source)` / `validateMetaState(meta)` / `parseMeta` / `serializeMeta`;
- `recordRunResult(meta, result)` → `{ ok, isRecord, earned, meta }`;
- `compareRuns(a, b)` — единственное правило порядка;
- `dailySeed(date)` и `dailyKey(date)` — сид дня и его подпись;
- `metaModel(meta, language, date)` — всё, что рисует экран «Записи».

Рантайм: `loadMetaState()` при загрузке, `recordFinishedRun(result)` на экране
итогов, `openRecords()`/`closeRecords()` для экрана из меню.

## Сид дня

Кнопка «Играть сид дня» в записях начинает забег ровно с этим сидом — тот же
подземный мир у всех до полуночи UTC. Это обычный забег: он идёт в ту же
таблицу лучших и в те же итоги.

## Что дальше

Отдельной таблицы по сиду дня пока нет: результат дня смешивается с обычными
забегами. Логичный следующий шаг — своя строка «лучшее за сегодня».
