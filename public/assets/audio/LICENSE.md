# Audio samples / Аудио-сэмплы

Every file in this directory is a CC0 1.0 (public-domain dedication) sample,
converted to mono 44.1 kHz MP3, peak-normalised to −3 dBFS and, where noted,
trimmed. The originals carry no attribution requirement; the authors are
credited here out of courtesy.

Все файлы в этом каталоге — сэмплы под CC0 1.0 (общественное достояние),
сконвертированы в моно MP3 44,1 кГц, пик выровнен на −3 dBFS, часть обрезана.
Указание авторства не требуется, авторы названы из уважения.
