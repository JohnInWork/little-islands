# Маленькие острова

Мобильная 2D roguelike/RPG, вдохновлённая системной глубиной NetHack и Pathos.
Игрок тапает по открытой клетке и указывает путь; герой сам идёт, сражается и
подбирает добычу. Управление остаётся простым, а решения создают процедурные
этажи, экипировка и события.

**▶ [Играть в браузере](https://johninwork.github.io/little-islands/)** — без
регистрации и скачивания.

## Игровая основа

- Генерируемые из seed этажи с комнатами, петлями, коридорами и достижимым выходом.
- Туман войны, путь по тапу/клику, WASD, преследование и автоматический ближний бой.
- Опыт, уровни, здоровье, рост сложности и сохранение прогресса.
- 24 активных монстра, 36 видов добычи, четыре события и четыре темы подземелья.
- Двенадцать мест, расходники, массовый разбор и восемь слотов экипировки.
- Броня, головные уборы, оружие, щиты и обувь отображаются на paper-doll героя.
- Версионированное локальное сохранение с backup и безопасным восстановлением.
- Интерфейс почти без слов, рассчитанный прежде всего на экран 390 × 844.

Это уже играбельный вертикальный срез и основа большой RPG, но пока не полная
копия объёма NetHack. Следующие системы: неопознанные зелья и свитки, проклятия,
сопротивления, статусы, выбор события иконками, уникальные комнаты и мини-боссы.

## Управление

- **Телефон / мышь:** нажать на любую открытую проходимую клетку.
- **Клавиатура:** WASD или стрелки.
- **Бой и подбор:** происходят автоматически рядом с целью.
- **Рюкзак:** единственная кнопка справа внизу; Escape закрывает его на компьютере.

## Разработка

Нужен Node.js 22 или новее:

```bash
npm ci
npm run check
npm run dev
```

Стек: Vite, Canvas 2D и обычные JavaScript-модули. Правила, контент и отображение
разделены, поэтому новые предметы и монстры добавляются данными, а не копированием
логики в игровой цикл:

- `tools/dcss-rpg-content.js` — каталоги монстров, предметов и событий.
- `tools/dcss-rpg-core.js` — генерация, поиск пути и правила сохранения.
- `tools/dcss.js` — Canvas, управление, бой и визуальное представление.
- `docs/2D-RPG-FOUNDATION.md` — контракты и безопасные рецепты расширения.

GitHub Actions запускает детерминированные тесты и публикует `main` в Pages.

## Графика и лицензии

Локальная библиотека содержит 3383 неизменённых PNG официального
[репозитория тайлов Dungeon Crawl Stone Soup](https://github.com/crawl/tiles),
опубликованных под CC0 / public-domain dedication. Браузер загружает только
активный каталог. Источники сохранены в
[`public/assets/dcss-preview/LICENSE.md`](public/assets/dcss-preview/LICENSE.md) и
[THIRD_PARTY_ASSETS.md](THIRD_PARTY_ASSETS.md).

Прежний 3D-прототип остался в истории git и больше не является активной игрой
или направлением разработки.
