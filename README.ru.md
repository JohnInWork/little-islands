# Маленькие острова

Небольшое 3D-приключение для телефона. Рыцарь, горстка гексов, три стража и портал на следующий остров. Нажимаешь, куда идти, — герой сам перемещается, сражается, добывает кристаллы и открывает сундуки. На экране почти нет слов: только иконки, анимации и ещё немного добычи.

**▶ [Играть в браузере](https://johninwork.github.io/little-islands/)** — рассчитано на телефон, работает и на компьютере. Без регистрации и скачивания.

![Рыцарь исследует остров из гексагонов](screenshots/island.png)

## Как играть

- **Одно нажатие — одна команда.** Выбери скелета, кристалл, сундук или свободный гекс. Рыцарь сам найдёт путь и выполнит действие. Удары, добыча киркой и открытие крышки сундука анимированы.
- **Три стража — один выход.** Победи двух скелетов и большого стража, чтобы открыть портал. На следующих островах меняются позиции встреч и декорации; чередуются три визуальных биома.
- **Две кнопки в бою.** Меч запускает круговой удар с перезарядкой. Зелье восстанавливает половину здоровья. Лагерь полностью лечит один раз.
- **С каждым островом чуть сильнее.** Между островами монеты улучшают урон, здоровье или запас зелий. При развитии оружия меняется вид экипировки. Поражение не отнимает монеты и улучшения.
- **Можно вернуться позже.** Прогресс автоматически сохраняется в этом браузере. После первой полной загрузки игра работает офлайн; поддерживающие это браузеры позволяют добавить её на домашний экран.

## Запуск

Нужен Node.js 22 или новее:

```bash
npm ci
npm run dev
```

Готовая сборка:

```bash
npm run build
npm run preview
```

Открыть `http://localhost:4173`. На телефоне в той же Wi-Fi-сети — сетевой адрес из вывода preview-сервера. GitHub Actions автоматически собирает и публикует ветку `main` на GitHub Pages.

## Стек

Three.js, Vite и обычный JavaScript. Инстансинг гексов, скелетные анимации, мягкие тени, синтезированные звуки и небольшой интерфейс из иконок. Без игрового сервера и внешнего API.

- `src/main.js` — игровой цикл, маршруты, бой, эффекты и сохранение.
- `src/world.js` — острова, биомы, декорации и реакции объектов.
- `src/actors.js` — персонажи, анимации и видимая экипировка.
- `src/ui.js` / `src/style.css` — адаптивный HUD и оверлеи.
- `public/sw.js` — офлайн-кеш в пределах игры.
